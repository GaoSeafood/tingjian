# 听见

一个自托管的视频听写与文案工作台。上传本地视频或粘贴公开视频链接后，系统默认只进行语音听写；听写完成后，再由用户主动选择“找亮点”或“复刻改编”。

## 第一版能力

- 本地视频或音频上传，最大文件大小可配置
- B站、抖音、YouTube、小红书、微博等公开视频链接解析，支持从整段分享文案中自动提取链接，也支持腾讯等直链
- 支持 MiMo-V2.5-ASR 或自定义 Whisper 兼容 ASR，长音频自动分段并生成时间码
- 保留 OpenAI Whisper 兼容的自定义 ASR 接口
- 可编辑听写稿，支持复制及 TXT / SRT 导出
- 用户主动触发找亮点：时间点、原话、推荐理由、标题、分类与评分
- 用户主动触发复刻改编，可填写新的主题或改编方向
- Sub2API 先调用 Gemini，失败时切换 GPT
- 支持为 GPT 备用路由单独配置另一个 Sub2API Key（适配不同分组）
- 单管理员登录、任务隔离、持久化任务队列与历史记录
- 原视频默认 24 小时后删除，也可以立即删除；历史记录支持手动删除，失败任务的原媒体也会在 24 小时后清理
- 长链接任务会根据时长自动切换为只下载音频模式，避免下载和转码不必要的视频流

## 架构

- 前端：React + Vite
- API：FastAPI
- 后台任务：RQ + Redis
- 数据库：PostgreSQL
- 视频处理：FFmpeg + yt-dlp
- 部署：Docker Compose

## 部署

```bash
cp .env.example .env
# 编辑 .env，至少设置登录密码、SESSION_SECRET 和数据库密码
docker compose up -d --build
```

服务启动后，用管理员账号进入“接口设置”，填写 MiMo API Key、Sub2API API Key 和模型名。密钥会加密保存且不会在页面回显。

服务默认只监听 `127.0.0.1:18092`。在 Tailscale 服务器上可将 `APP_BIND` 设置为该服务器的 Tailscale IPv4，避免直接暴露到公网。

## 安全说明

- `.env` 不进入版本库，不要在聊天、截图或日志中公开任何 API Key。
- URL 下载限制为 HTTPS、公网地址与受支持的平台，避免请求进入服务器内网。
- 分享给朋友时应新增独立账号与邀请机制，不建议共享管理员密码。
- 仅处理你有权使用和下载的视频内容。
